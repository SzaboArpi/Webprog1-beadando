JavaScript menü

A JavaScript menü az Utazás -> helység adataival dolgozik, az adatbázist megjeleniti, hozzá lehet adni-, szekeszteni- és törölni adatot. Használata kényelmes és egyszerű.

React menü

A React menü hasonlóan az elözöhöz a Utazás adatbázisát felhasználva teljesíti a CRUD feltételeit is. Tartalmaz keresést, rendezést, illetve új szállodát is hozzá adhatunk az adatbázishoz, szerkezhetjünk avagy törölhetjük a meglévőket.

OOJS menü

Az OOJS menü egy grafikus alkalmazás mely lehetövé teszi, hogy objektumok használatával a Fömenü ponthoz menüpontokat adjunk hozzá, illetve hogy x és y kordináta szerint mozgassuk a Fömenü buborékját. A programhoz létrehoztuk úgynevezett "oojs.js" fájlt is.
